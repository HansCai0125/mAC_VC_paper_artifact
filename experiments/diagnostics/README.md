# Diagnostics on archived detector outputs

Offline analyses behind paper Table 4, Table 6(b), Sec. 5.4 and Supplementary Secs. S2, S3, S5 and S8. Nothing is trained and no detector or SAM weights are loaded: the code reads the existing prediction caches, the continuous-polygon audit and the cached SAM outputs, all read-only.

## Run

From the repository root:

```bash
python experiments/diagnostics/run_experiment.py
```

The defaults are `MODE = 'formal'` and `RUN_NAME = 'main'`. Dependencies are numpy, pandas and pycocotools.

## The four analyses

1. **A: residual support among unmatched targets.** Two datasets, three YOLO models, five seeds each. MS-COCO is validated against polygon ground truth; VisDrone is described at box level only.
2. **B: foreground enrichment of the extra coverage.** MS-COCO, three models, five seeds. Each eligible target gets 200 deterministic random translations; an area reference, a translation reference and the density difference are computed.
3. **C: information beyond existing geometry and instance metrics.** Reuses the 4,000 held-out images of the frozen SAM split at theta = 0.25 and at most 20 prompts per image. Compares grouped cross-validated R^2 of an extended baseline with and without VC, and reports owner-independent foreground recall and a mechanism check for two ownership rules.
4. **D2: controlled annotation coarsening.** Same-class targets are merged by connected components, keeping all singletons. delta = 0 is the main analysis; 0.25 and 0.5 are sensitivity analyses.

A crowd-region analysis (D1) was not run, because the registered caches were already crowd-filtered.

## Outputs

Formal outputs go to `results/main/`:

- `protocol.json`: fixed parameters, input identities and code hashes.
- `reports/main_results.csv`: main effects with image-level intervals.
- `reports/primary_tests_holm.csv`: the 12 pre-specified primary comparisons with Holm correction.
- `reports/A_seed_mean_SD.csv`, `B_C_seed_mean_SD.csv`: mean and sample SD across seeds.
- `reports/A3_strata_*.csv`: stratum boundaries, sample sizes, exclusions and per-seed comparisons.
- `reports/C_folds_*.csv`: cross-validation audit. The matching `C_oof_*.csv` tables are regenerated by the run and are not included.
- `reports/D2_per_seed.csv`, `exclusions.csv`: coarsening results and exclusion reasons.
- `complete.json`: written only after everything has finished.

The intermediate `diagnostics.sqlite` and the `per_run/` tables are also regenerated by the run and are not included.

## Interrupting and resuming

Rerun with the same code, parameters and `RUN_NAME`. Finished images are skipped and existing results are never deleted. Input checksums are verified again. After changing code or parameters, choose a new `RUN_NAME`; the program refuses to mix protocols in one output folder. Do not start two runs with the same `RUN_NAME`.

## Check modes

```bash
python experiments/diagnostics/run_checks.py
```

```bash
python experiments/diagnostics/run_experiment.py --mode preflight
```

```bash
python experiments/diagnostics/run_experiment.py --mode smoke --run-name my_smoke_v1
```

Smoke mode uses 12 fixed images from seed 0 of each model, 3 translations, 50 bootstrap replicates and 2x2 cross-validation. It only checks the execution chain and must not be read as a paper result. Formal mode uses 200 translations, 2,000 bootstrap replicates and 5-fold cross-validation repeated 10 times.

Most of the runtime is the exact polygon translation in B, which runs on the CPU. Progress is saved after every image.

The frozen analysis specification is in `PLAN.md`.
